# Uses

Last updated: September 8, 2026.

This page gathers the tools, hardware, software, and setup I use for work, learning, writing, and personal projects.

It is intentionally part of my [About me](./my-journey.md) section because the tools I choose are also part of how I think, build, communicate, and learn in public.

<details>

The idea connects with [uses.tech](https://uses.tech/), a directory of personal pages where people share the tools they use. I like it because it helps discover people with similar interests, understand how they work, and start unexpected conversations.

If you have your own website, this may be a good excuse to create your own uses page.

</details>
